# Hand-Controlled-3D-Particle-System

An interactive **Hand-Controlled 3D Particle System** that combines hand-tracking technology with real-time 3D particle visualization.

The project explores the use of computer vision and gesture-based interaction to control a dynamic particle environment using hand movements.

## 📌 Project Overview

The Hand-Controlled 3D Particle System is an interactive visual application where users can control and manipulate a 3D particle system using hand gestures.

Instead of relying on traditional mouse or keyboard controls, the project introduces a more natural interaction method through hand movement and gesture recognition.

## ✨ Features

* ✋ Hand gesture-based interaction
* 🌌 Real-time 3D particle visualization
* 🖱️ Interactive particle manipulation
* 🎨 Dynamic visual effects
* ⚡ Real-time user interaction
* 🧠 Computer vision-based control
* 🖥️ Interactive graphical experience

## 🛠️ Technologies

The project combines technologies for:

* **3D Graphics** — Rendering and controlling the particle environment
* **JavaScript** — Application logic and interaction
* **Hand Tracking / Computer Vision** — Detecting and interpreting hand movements
* **Web Technologies** — Providing the interactive browser-based experience

## 🎮 How It Works

The basic interaction flow is:

```text
User Hand Movement
        │
        ▼
Hand Detection / Tracking
        │
        ▼
Gesture & Position Data
        │
        ▼
Interaction Logic
        │
        ▼
3D Particle System
        │
        ▼
Real-Time Visual Response
```

The user's hand movements are detected and translated into interaction data, which is then used to influence the behavior of the 3D particles.

For the best experience, use a browser with camera access and enable the required permissions when prompted.

## 📷 Camera Permissions

Since the project uses hand-based interaction, camera access may be required.

When prompted by the browser:

1. Allow camera access.
2. Position your hand within the camera view.
3. Move your hand to interact with the particle system.
4. Experiment with different gestures and movements.
